# FRIP – Economic Load Dispatch Program

A Python-based Economic Load Dispatch application developed to identify economical generator operating combinations for off-grid diesel power plants.

## Key Features
- Generator operational status input
- Individual generator fuel rate curves
- Minimum and maximum generation capacity constraints
- Generator combination evaluation
- Fuel consumption calculation
- Economic dispatch selection
- 24-hour demand input interface

## Technologies Used
- Python
- Tkinter
- Mathematical Modeling
- Polynomial Regression / Fuel Rate Curves

## Purpose

The program aims to support power plant operations by identifying generator combinations that can meet electricity demand while minimizing estimated fuel consumption.

## Disclaimer

This project is presented for educational and professional portfolio purposes. Generator parameters and datasets used in the public version should be anonymized or illustrative. The program is not intended for direct operational deployment without further validation and testing.
